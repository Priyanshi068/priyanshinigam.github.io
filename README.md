# Priyanshi Nigam – Portfolio

Static portfolio website (HTML + CSS, no build step).

## Structure
```
index.html
css/style.css
assets/
  profile.jpg
  tripnest-screenshot.jpg
  Priyanshi_Nigam_Resume.pdf
```

## Deploy on GitHub Pages
1. Push these files to a repo (e.g. `portfolio`).
2. Settings → Pages → Source: `main` branch, `/ (root)`.
3. Site goes live at `https://<username>.github.io/portfolio/`.
